# reconnaissance-faciale
# 🔐 Face Recognition Biometric Authentication System

This project is a **biometric authentication system** using facial recognition and built with Streamlit.

It allows users to:
- Register their face (Enrollment)
- Login using face recognition
- Get a confidence score
- Prevent unauthorized access

---

#  Features

✔ Face Enrollment (User Registration)  
✔ Face Authentication (Login System)  
✔ Confidence Score Matching  
✔ Simple Biometric Database  
✔ Real-time webcam capture (Streamlit)  

---

#  Technologies Used

- Python 
- Streamlit
- OpenCV
- face_recognition
- NumPy

---

#  How It Works

1. The user registers their face
2. The system extracts facial features (encodings)
3. Encodings are stored in a local database
4. During login, the system compares faces
5. A confidence score is calculated
6. Access is granted or denied
